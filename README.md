# Sales-Performance-dashboard
Interactive Sales Performance Dashboard built with Power BI for KPI tracking and business insights.

## Project Overview
This dashboard analyzes sales performance including sales, profit, cost, and margin with YTD vs LY comparison.

## Tools
- Power BI
- DAX
- Data Modeling
